TITLE
AlienX 2D (ISN): A Continuous Rotation- and Scale-Invariant Operator on Geometric
Manifolds, with a Cross-PDE Demonstration on Gross-Pitaevskii

CREATORS
Yaka, Eric Heylel Danjuma (Elbàlor / The Digital Necromancer)
Affiliation: Capital Software / Next Gen Tech, Abuja, Nigeria

DESCRIPTION
AlienX 2D (Isomorphic Spatial Net) is a neural operator that operates on
continuous geometric manifolds instead of fixed grids, with native rotation and
scale invariance. Each node lives on a spatial graph with an isotropic
24-neighbor circular stencil (radius sqrt(8)); a local SO(2) frame makes
displacements rotation-equivariant; edge features encode local angle as an even
complex-harmonic embedding; a constant physical scale depth makes the operator
scale-blind by construction. No data augmentation. No learned geometry.

Strict operator-level equivariance is verified directly: pred(R·k) = R·pred(k)
is bitwise exact (0.000e+00) under D4 (90/180/270 degrees) with live message
passing, and the eigh sign boundary in the frame fallback is closed by the
sign_lock.

Cross-PDE demonstration (v3): the architecture is PDE-agnostic — only the outer
shell changes (scalar field k = |psi|^2, regime parameter g, invariant
integral|psi|^2 = 1). On the 2D Gross-Pitaevskii equation (focusing, split-step
Fourier ground truth), two runs with 416,150 parameters each establish:
(1) a precision run — 0.34% single-step relative RMSE, phase-ablation
degradation of 108.6x (the phase mechanism is load-bearing), rotation sweep
0.41% +/- 0.03% over 24 angles, zero-shot scale transfer 16x16 to 256x256 at
0.32-0.37%; (2) a generalization run with randomized initial conditions and a
K=1->3->5 rollout curriculum — 1.07% +/- 0.21% over 16 unseen initial
conditions, phase ablation 61.4x. The claims are kept separate by design and
the run A initial-condition family is deterministic (disclosed).

The release contains the Darcy checkpoint, the two GP training scripts, two
evaluation suites, raw logs for every number, the training history and result
JSON, the Dark Necromancer training graph, the dark-field rollout comparison,
the strict equivariance test, the complete paper (editable docx + PAPER.md),
and the full debugging log. Every number is regenerable on a single T4 GPU.

NOTES: All evaluations are single-step. The multi-step (K=5) rollout evaluation
and the 3D GP run are the next steps; neither is claimed in this release.
